# API Reference

Base URL: `http://127.0.0.1:8000` (local only by default).

Interactive docs are served at `/docs` (Swagger UI generated by FastAPI).

## `GET /api/health`

Liveness check. → `{"status": "ok", "app": "VeilShare Edge", "version": "0.1.0"}`

## `GET /api/runtime`

Runtime/backend telemetry: platform, CPU, memory, ONNX Runtime version and
available providers, whether `QNNExecutionProvider` (Snapdragon NPU) is
present, and an honest `acceleration_status`.

```bash
curl -s http://127.0.0.1:8000/api/runtime | python -m json.tool
```

## `GET /api/demos`

Lists the built-in synthetic demo screenshots.

## `GET /api/demos/{demo_id}/image`

Serves a demo PNG (`fake_dashboard`, `fake_student_portal`, `fake_invoice`,
`confidential_slide`).

## `POST /api/scan`

Scan an uploaded image **or** a built-in demo. Multipart form fields:

| Field | Type | Description |
|---|---|---|
| `file` | file | image upload (PNG/JPEG/WebP) |
| `demo` | string | built-in demo id (alternative to `file`) |
| `ocr` | string | `auto` (default) \| `easyocr` \| `simulated` |

```bash
curl -s -X POST http://127.0.0.1:8000/api/scan \
  -F demo=fake_dashboard | python -m json.tool
```

## `POST /api/capture`

Capture the screen (or region) and scan it. Requires the optional `mss`
package on a desktop machine; returns 503 with a clear message otherwise.
Form fields: `monitor` (0-based), optional `x`, `y`, `w`, `h`, `ocr`.

## `POST /api/redact`

Render the Safe Share image for a previous scan. JSON body:

```json
{"scan_id": "8f14e45fceea167a", "mode": "blur", "finding_ids": ["F01", "F03"]}
```

`mode`: `blur` | `blackout` | `pixelate`. `finding_ids` is optional
(defaults to all findings). Returns `image/png` bytes.

```bash
curl -s -X POST http://127.0.0.1:8000/api/redact \
  -H 'Content-Type: application/json' \
  -d '{"scan_id": "…", "mode": "pixelate"}' -o safe_share.png
```

## Error model

- `400` — unreadable upload / missing source / bad mode
- `404` — unknown demo id, or scan id expired from the in-memory store
- `503` — screen capture unavailable (no `mss`)

## Static UI

`/` serves `frontend/index.html`; all UI assets are same-origin and all
fetches use relative URLs — the app works behind any reverse proxy without
CORS configuration.
